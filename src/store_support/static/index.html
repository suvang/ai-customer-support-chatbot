How this assistant works

What it is

A demo customer-support chatbot for a small online store. It answers questions about orders, shipping delays, refunds, customers and products.

Where answers come from

  • Store records: customers, products and orders (see the left panel).
  • Policies: short support documents like the refund and shipping rules.

It never makes things up. If it can't find the answer in either place, it says so and suggests contacting a person.

Reading a reply

  • Order cards show the records the answer used.
  • Sources show which policy was quoted. Click one to read the passage.
  • How I found this lists each lookup the assistant made.

Memory

The assistant remembers the last few messages of this chat and the records you were discussing, so you can ask follow-ups like “what did he order last?” or “can I get a refund for it?”. The Remembering bar above the message box shows what it has in mind. New chat clears it.

Two modes

  • AI mode (when OPENAI_API_KEY is set): an OpenAI model decides which lookups to run and writes the reply.
  • Offline mode (no key): simple keyword matching finds records and policies, and the reply is built from templates.
